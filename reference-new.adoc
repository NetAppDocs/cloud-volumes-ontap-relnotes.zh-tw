:hardbreaks:
:allow-uri-read: 
:nofooter:

[role="lead"]
現在您可以部署和升級到 Cloud Volumes ONTAP 9.19.1。您可以在 NetApp Console 中查看此版本的基本版本以及可用於部署和升級的最新修補程式版本。

要進一步瞭解 Cloud Volumes ONTAP 的功能、支援的組態、限制等資訊，請參閱 https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/index.html["Cloud Volumes ONTAP 文檔"^]。



[[9-19-1-10-august-2026]]
== 9.19.1（2026年8月10日）

Cloud Volumes ONTAP 9.19.1 正式版 (GA) 現已發布，目前僅支援在 Amazon Web Services (AWS) 和 Google Cloud 上部署和升級。此版本不支援在 Microsoft Azure (Azure) 上部署和升級。



[[upgrade-notes]]
== 升級附註

請閱讀這些附註、深入瞭解升級至此版本的相關資訊。



[[how-to-upgrade]]
=== 如何升級

Cloud Volumes ONTAP的升級必須透過控制台完成。您不應使用系統管理員或 CLI 升級Cloud Volumes ONTAP 。這樣做會影響系統穩定性。

https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-updating-ontap-cloud.html["了解控制台通知您時如何升級"^]。



[[supported-upgrade-path]]
=== 支援的升級途徑

您可以在 AWS 和 Google Cloud 中將 Cloud Volumes ONTAP 從 9.18.1 升級到 9.19.1。主控台將提示您將符合條件的 Cloud Volumes ONTAP 系統升級至此版本。


NOTE: 在 Azure 中，不會提示您升級至 9.19.1，因為此版本在該雲端供應商中無法部署和升級。



[[downtime]]
=== 停機

* 單節點系統的升級會使系統離線最多 25 分鐘，在此期間 I/O 會中斷。
* 升級 HA 配對不會中斷營運， I/O 也不會中斷。在此不中斷升級程序期間，每個節點都會一起升級，以繼續為用戶端提供 I/O 服務。
